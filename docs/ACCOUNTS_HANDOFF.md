list_accounts returns balance_snapshot or null. Values use integer cents, account currency, as_of date and estimate flag. Latest snapshot is greatest as_of then newest sequence. All revisions/older same-day corrections remain in account_balance_snapshots; there is no browser history-list endpoint yet. Future charts need a checked history query and latest-per-date handling. A history point must state which accounts have balances and carry-forward ages, rather than silently treating missing values as zero.

Current net worth excludes archived and include_in_net_worth=false accounts. It sums checking/savings/investment/asset/legacy-other as Assets and subtracts signed credit/loan/mortgage amounts owed as Debts. Negative liabilities are credits; negative bank balances reduce assets. Checking and savings are cash, not investments/property. Never combine currencies without a deliberate verified FX feature. Show partial/missing and stale coverage prominently. The current section subtotals intentionally show all active listed balances, including excluded accounts; these are not net worth totals.

Types and currency are immutable after account creation to protect history and card-payment semantics. Source account metadata may mark currency as assumed; do not silently relabel or convert balances. Property/other values are estimates, investments use Market Value, bank accounts Balance, debts Amount owed. Existing source imports retain their earlier contract and do not populate balance snapshots. Archive is a recoverable visibility/net-worth setting, not deletion of historical ledger data or a ban on old imports.

Overview specifics: summarizeWorth calculates exact cents with checked BigInt aggregation, returning unavailable for unsafe display totals. Currency is independent of activity filters; missing/invalid entries yield Partial coverage rather than zeros. Positive-only asset slices exclude negative asset adjustments, while negative liabilities reduce Debts. Both adjustments are disclosed next to the donut. Chart/metric controls open an in-memory account subset with a reset banner; account-name controls focus the individual editor. No backend change was needed for this phase. Future historical aggregation must use its own checked API and continue these missing/currency/archive/inclusion rules deliberately; a collection of current values is not a historical trend.
